## Findings

- The feedback path works as built: complaints are recognised, the last run
  is marked wrong in the history, the retry carries the original
  instruction and `retry_of`.
- Without the buffer's lines the model guesses at text it cannot see
  (`Date:` for `**Date:**`) and writes cursor-relative searches. Sending the
  lines with numbers fixed every round 1–3 failure that was not a model
  error.
- Haiku makes errors Sonnet does not (line numbers after an undo, "select"),
  at the same speed. Sonnet is the default from `429c05f`.
- A run with no error is not a run that worked: `changed: false` now tells
  the next request when nothing changed.
